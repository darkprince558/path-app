# Not 404 brand files

PNG exports of the logo and favicon for slides, Devpost and social posts. The
source of truth stays in code: the wordmark in `apps/web/src/components/Logo.tsx`
and the favicon in `apps/web/public/favicon.svg`. Colors and type are in
`apps/web/DESIGN.md`.

| File | Size | Use |
| --- | --- | --- |
| `not404-logo-card-1500x1000.png` | 1500×1000 | Devpost thumbnail (3:2), slides |
| `not404-logo-for-light-backgrounds.png` | 1541×496, transparent | Forest text for white or paper backgrounds |
| `not404-logo-for-dark-backgrounds.png` | 1541×496, transparent | Paper text for dark backgrounds |
| `not404-logo-on-night.png` | 1541×496 | Wordmark on the night background |
| `not404-favicon-512.png`, `not404-favicon-1024.png` | square | App-style icon: coral ring on night |
| `not404-ring-transparent-512.png` | 512×512, transparent | The ring alone ("you are here") |

Rendered from the same geometry as the site, in Overpass Black, with letter spacing -0.025em and the ring 0.78em wide.
